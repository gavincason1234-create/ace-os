ACE

Local intelligence

A lightweight Linux system with its own AI built in — no account, no subscription, no data leaving the machine. Built for one modest laptop and tuned until it felt fast on it.

Download ISO Install guide Source

Debian 13 · XFCE · amd64 · ~1.9 GB · free and open

What it is

AI that lives here

Qwen2.5 runs on your own CPU through llama.cpp. Download the model once, then unplug the internet — it keeps working.

It listens and answers

Speak instead of typing. Whisper transcribes on-device, espeak or piper answers out loud, and spoken commands open apps and read out battery, memory and time.

Built for weak hardware

Compiled without AVX for the Celeron N4020, compressed zram swap for 4 GB of RAM, and a desktop that idles in about 600 MB.

Looks the part

Black ground, blood-red accents, a live digit-rain wallpaper and an animated RGB edge ring you can switch off when you want the cycles back.

Real tools

ripgrep, fd, bat, fzf, btop, duf, neovim and tmux — plus ace-sys for health checks, cleanup and network diagnosis.

Nothing phones home

No telemetry, no account, no cloud dependency. The only network traffic is what you start yourself.

└─▶ how do I free up disk space?

You can clear the caches safely with ace-sys clean — it shows
what it will delete and how much you get back before touching
anything. The apt package cache is usually the biggest win.

Install it

  1. Download the ISOThe button at the top. About 1.9 GB.
  2. Write it to a USB stick8 GB or larger, with Rufus or balenaEtcher. The stick gets erased.
  3. Boot from the stickTap F2 at power-on, turn Secure Boot off, save with F10, then tap Esc and pick the USB drive.
  4. Run the installerDouble-click Install on the desktop and follow it through. Around 20 minutes.
  5. Wake the AIOpen a terminal, type ace, then /setup to fetch the brain. Add voice with ace-voice --setup.

Rufus showing no drives? It hides sticks larger than about 64 GB on purpose. Click Show advanced drive properties and tick List USB Hard Drives — yours will appear.

Honest limits

The AI answers at a few words per second on a 2-core Celeron. It is good for questions, explanations, drafting and system help — it is not a cloud model and will not pretend to be. Installing replaces whatever is on the laptop, so copy anything you want to keep first.
